# Campus Library

A browser-based library demo for exploring a campus book collection and managing reservations.

## Features

- Sign in with a 10-digit registration number.
- Search and filter books by department and availability.
- Reserve available books, view active reservations, and cancel them.
- Track the 24-hour reservation hold in the browser.

## Run locally

Open `login-copy.html` in a browser to sign in, then browse the catalogue. This demo stores its sign-in status and reservations in browser storage; it does not use a server or verify real accounts.
